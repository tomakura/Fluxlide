# Linuxでの動作の確認（仮想ディスプレイ）

> 実施日: 2026-10-21。[完成までの手順](roadmap.md)の段階1の1番（WindowsとLinuxの実機での確認）のうち、クラウド上のLinuxのコンテナでできる範囲を確かめた。実機、実際のGPU、HDMIの外部ディスプレイ、音声の出力機器はない。

## 1. 環境

| 項目 | 内容 |
| --- | --- |
| OS | Ubuntu 24.04.5（コンテナ） |
| 画面 | Xvfb（X11の仮想ディスプレイ、1600×1000）。ウィンドウマネージャーなし |
| GPU | なし。Mesaのllvmpipe（LLVM 20.1.2）によるソフトウェアのVulkan |
| webview | WebKitGTK 4.1 |
| FFmpeg | 6.1.1（Ubuntuのパッケージ版） |
| 入れたパッケージ | CIと同じ `libwebkit2gtk-4.1-dev` など、`libasound2-dev`、`mesa-vulkan-drivers` |

アプリは `npx tauri build --debug --no-bundle` でビルドし、`xdotool` で操作して、画面写真で確かめた。

## 2. 結果

| 確認項目 | 結果 |
| --- | --- |
| ビルド、fmt、clippy、テスト | 通った。GPUを使うテストも、llvmpipeで実際に描いて通った（飛ばされていない） |
| 管理画面の表示 | 日本語を含めて正しく表示された。描画エンジンは llvmpipe（vulkan）と表示された |
| ファイルを選ぶダイアログ | GTKのダイアログで写真と動画を追加できた |
| 上映ウィンドウ | GTKのウィンドウにwgpuの描画面を作れた。全画面で表示された |
| 写真と動画の再生 | 写真（4032×3024のJPEG）→動画（1080p30）→写真を、ぼかし背景とキャプション付きで、トランジションでつないで再生した |
| Escで上映を終わる | X11ではグローバルショートカットが効き、上映ウィンドウが閉じた |
| 管理画面のプレビュー | 表示された（[管理画面の中のプレビュー](spike-preview.md)） |
| 音声の出力 | 出力機器がないため、「音声を出力できません」と表示され、映像だけで再生が続いた |

## 3. 確かめられなかったこと

- 実機と実際のGPU（Vulkan）での描画の速さ。llvmpipeはCPUで描くため、フレームレートは参考にならない。
- Wayland。グローバルショートカットが使えないため、Escの代わりの方法が要る（[上映ウィンドウ](spike-presentation-window.md)の6）。WaylandでGLESを使う場合の表示ハンドルの受け渡しも未確認。
- HDMIでつないだ外部ディスプレイ、複数の画面での表示先の選択。仮想ディスプレイは1枚だけだった。
- 音声（ALSA、PulseAudio・PipeWire経由）での動画の音、BGM、音ズレ補正。
- ウィンドウマネージャーがある環境での、上映中の管理画面の操作（前面への切り替えなど）。
- Windowsのすべて。

これらは、実機を持つ人が確かめる必要がある。手順は、[README](../README.md)の「開発・ビルドについて」でアプリを起動し、管理画面から写真・動画、BGMのフォルダ、音ズレ補正を指定して上映し、表示される計測値を記録する。
