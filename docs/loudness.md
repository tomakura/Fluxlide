# BGM と動画の音量をそろえる

> 決定日: 2026-11-06（相談して決定）。処理は [`media/loudness.rs`](../crates/fluxlide-engine/src/media/loudness.rs)（測る）、[`show.rs`](../crates/fluxlide-engine/src/show.rs) の `Loudness::gain`（ゲイン）、[`bgm.rs`](../crates/fluxlide-engine/src/bgm.rs) の `TrackGains`（BGM）、[`slideshow.rs`](../crates/fluxlide-engine/src/slideshow.rs) の `sound_gain`（動画）、[`src-tauri/src/loudness.rs`](../src-tauri/src/loudness.rs)（BGMの測った値を残す）にある。

曲ごと・動画ごとに音の大きさがばらばらだと、曲が変わるたびや動画が始まるたびに音量が跳ねる。ファイルごとの大きさを測り、同じ大きさにそろえてから、BGMの音量と動画ごとの音量を掛ける。

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 方式 | ファイル全体のラウドネス（EBU R128 の統合ラウドネス、LUFS）と true peak を FFmpeg の `ebur128` で測り、ファイルごとに1つのゲインを掛ける | 再生しながら音量を変え続ける方式（`loudnorm` など）は、曲の途中で大きさが揺れる。今の再生の仕組み（リングバッファにデコードしてミキサーで混ぜる）にもそのまま入る |
| 目標 | -16 LUFS。BGMも動画も同じ | BGMを動画より小さくする関係は、BGMの音量（初期値50%）で残る |
| 上げすぎない | 上げるのは、true peak が -1 dBTP を超えない分まで。最大 +12 dB。下げるのはいつでも | 音割れしない。無音に近いものを大きくしすぎない |
| 切り替え | 「BGM と動画の音量をそろえる」1つで、BGMと動画の両方 | 相談して決定 |
| 初期値 | 新しい作品は入。版2以前の作品は切（[保存の形](project-storage.md)の定義の変換） | 前からある作品の聞こえ方を、開いただけで変えない |
| 動画を測るとき | 取り込みのとき。前からある作品の動画は、開いたときに裏で測る。測った値は素材（`Asset::loudness`）に残す | 素材と一緒に持ち運べる。音を読めない動画は、取り込みの失敗と同じ扱いにする |
| BGMを測るとき | 音楽タブで曲を選んだとき、そろえるを入れたときに裏で測る。まだのものは、BGMがその曲を開く直前に測る（その曲だけ少し遅れる） | 曲は作品にコピーしないので、測った値はアプリのデータフォルダの `loudness.json` に、パス・大きさ・変更日時と一緒に残す。ファイルが変われば測り直す |
| 測れない曲 | 再生できない曲と同じく、飛ばして知らせる | 音量を合わせられないまま流さない |
| 測り終わっていない動画 | そろえずに流す | 開いた直後の、裏で測っている間だけ |
| 動画の書き出し | 上映と同じ（同じ `Slideshow` と BGM を使う） | 上映と書き出しで聞こえ方を変えない |
