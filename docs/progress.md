# 進捗の記録

> 最終更新: 2026-10-22。[完成までの手順](roadmap.md)の段階1（技術検証）を実機での確認を除いて終え、段階2（土台）と段階3（最小限の製品）を終えた。

## 進め方

- 段階ごとに統合用のブランチを作る。段階1は `feat/stage1-tech-validation`、段階2は `feat/stage2-foundation`、段階3は `feat/stage3-mvp`。
- 項目ごとにブランチ（`wip/<名前>`）を分けて進め、終わったら統合用のブランチに `--no-ff` でマージする。
- 段階が終わったら、統合用のブランチから `main` へのPull Requestを出す。

## 実機で確かめてほしいこと

段階2と並行して、次を実機で確かめる。手順は各文書の「未確認のこと」にある。

- Windows: ビルド、上映ウィンドウ（WebView2でのデッドロックがないか）、動画の再生、音声、`h264_mf` での書き出し、FFmpegのビルドとCI
- macOS: HDMIの外部ディスプレイ、BGMと音ズレ補正（Bluetoothのイヤホン・スピーカー）、`h264_videotoolbox` での書き出しの画質と速さ、プレビューの速さ
- Linux: 実際のGPU、Wayland（Escの代わり、GLES）、音声（PulseAudio・PipeWire）
- すべてのOS: 実際のGPUでの、上映のフレームレート、書き出しの速さ、プレビューの速さ
