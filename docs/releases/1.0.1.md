# Fluxlide 1.0.1

保存と動画書き出しの不具合を修正した更新です。v1.0.0をお使いの方は更新してください。

- 書き出しを中止・失敗したとき、同じ保存先にあった既存ファイルを消してしまう不具合を修正しました。完成した動画だけを最後に置き換えます。
- 手動送りに設定した作品も、指定した表示時間で1周分の動画を書き出して終了するようにしました。
- ホームへ戻る・上映する・書き出す・アプリを終了する前に、編集の保存を待つようにしました。保存中と失敗を表示し、保存を再試行できます。
- ファイル設定画面・ホーム・上映中にも、操作画面で書き出しの進捗・完了・失敗を確認できます。書き出しに使用中の作品は削除できません。
- 上映開始の予約とプレビューの古い応答が、画面を移動したあとに有効になる不具合を修正しました。
- BGMの停止・書き出しの中止で素材を確実に解放するようにしました。
- タイルに分かれたHEICを全体の画像として取り込めるようにしました。実HEVCの通常・タイル・回転付きHEICを回帰試験に追加しています。
- 破損した設定を黙って初期化せず、理由と回復操作を表示します。初期化を選ぶと元データをバックアップします。
- 明るい写真に重なる小さなキャプションと、幅960pxの編集画面の表示を調整しました。
- 出力に指定ビットレートを反映し、容量を「目安」として表示します。Windowsで色情報が抜ける場合に備え、MP4にもBT.709を明記します。
- Tokioの既知の脆弱性を修正した版に更新しました。LinuxのGLibには上流の安全性修正を適用し、SvelteKitも更新しました。

Windows/macOSの同梱版はH.264・AAC、Linuxの同梱版はMPEG-4 Part 2・AACをMP4に格納します。Linux版の動画は再生先が対応していることを確認してください。選ばれる方式は書き出し画面にも表示します。

Windows実機で保存、外部画面上映、操作画面の映像表示、一時停止・送り・暗転、手動送り作品の書き出しを確認しました。3OSのCIと配布物の検査結果は[検証記録](https://github.com/tomakura/Fluxlide/blob/main/docs/manual-checks.md)に記録します。macOS/Linuxの実機、iPhone撮影写真、機器の抜き差し、4時間以上のネイティブ上映は未確認です。

証明書を設定していない配布物は未署名です。WindowsのSmartScreen、macOSのGatekeeperが警告を表示する場合があります。署名・公証済みの版とはしていません。

FFmpeg 9.0.2のソース、ビルド手順、Fluxlideのソース、ライセンス文、SHA-256一覧、ビルド元コミットの記録を、このリリースに添付します。FFmpegは改変しないLGPL構成の別プログラムとして同梱しています。FFmpegソースのSHA-256は `8c3850283eb25fa026482078a04051e0be17347b09ef81a0849bec15a96e002e` です。

H.264・HEVC・AACなどの特許に関する許諾は含みません。事業での配布・利用など、必要な許諾は利用条件に応じて確認してください。Display P3の色管理とHDRからSDRへの変換は行いません。
