# 手動の確認項目

> 作成日: 2026-10-22。リリースの前に、各OS（Windows、macOS、Linux）で次を確かめる。自動テストで確かめられないもの（画面の操作、実際の画面と音の出口、機器の抜き差し）を集めた。結果は OS ごとに「済み・日付・機器」を書き足す。

## 1. 作る

- [ ] ホーム画面の「＋ 新しいスライドショー」で作品ができ、編集画面になる
- [ ] 写真と動画をホーム画面にドロップすると、新しい作品ができて取り込まれる
- [ ] 取り込み中にコピーの進み具合が出て、その間にタイトルを入力できる
- [ ] HEIC の写真（iPhone で撮ったもの）を取り込める。縦に撮った写真が縦に出る
- [ ] 縦に撮った動画が縦に出る
- [ ] 対応していないファイルは、理由を出して断る
- [ ] スライドを番号の部分でつかんで並べ替えると、置いた位置に入る（上へ・下へ・末尾）。Alt + ↑ ↓ でも動く
- [ ] Ctrl+Z（macOS は ⌘Z）で元に戻り、Ctrl+Shift+Z で戻る。入力欄の中では入力欄の取り消しになる
- [ ] 文字を速く打っても、入力欄の文字が戻らない。日本語の変換が途切れない
- [ ] アプリを閉じて開き直すと、最後の状態が残っている（自動保存）
- [ ] 「ほかの場所から開く」で開いた作品が、ホーム画面の最近の一覧に出る

## 2. 見た目と音楽

- [ ] 見た目タブの各設定（デザイン、ウォーターマークの文字・画像、位置、不透明度、大きさ、縦横比、トランジション、表示時間、ゆっくりズーム、文字の大きさ）がプレビューに出る
- [ ] ウォーターマークの画像の選択をやめると、選択欄が元に戻る
- [ ] 間違いのある WGSL を追加すると理由が出て、正しいものはトランジションの一覧に出る
- [ ] 音楽タブで BGM のフォルダを選ぶと曲の一覧が出る。音量を動かしても一覧がちらつかない
- [ ] テスト音で、光と音が同時になるように音ズレ補正を合わせられる。Esc か「テスト音を止める」で止まる

## 3. 上映

- [ ] 「▶ 上映する」で出力先の選択が出る。「各画面に番号を表示」で各画面に番号が出て、3秒で消える。続けて押しても番号が残らない
- [ ] 画面が1台のときは、案内が2.5秒出てから始まる
- [ ] 開始前の画面（マークと題名）で止まり、Space か → で始まる。黒い画面にならない
- [ ] 前へ・次へ・一時停止・暗転が、操作画面のボタンと上映画面のキー（← → Page Up/Down Space B）で効く。プレゼン用のリモコンでも効く
- [ ] 一時停止で BGM も止まり、再開で戻る。一時停止中に次へを押すと、BGM も戻る
- [ ] 動画の音が映像と合っている。音のある動画の間は BGM が下がる
- [ ] 最後のスライドのあとで次へを押すと、終了の画面になる
- [ ] Esc で終わる。画面が2台以上なら操作画面で確認が出る
- [ ] 上映ウィンドウを OS の操作で閉じると（Windows は Alt+F4）、操作画面が編集に戻る

## 4. 機器の抜き差し

- [ ] 上映中に出力先の HDMI を抜くと、一時停止して操作画面に知らせが出る。挿し直すと、その画面に全画面で戻る
- [ ] 上映中に Bluetooth のスピーカーをつなぐと、音がスピーカーに移る。外すと、内蔵のスピーカーに戻る
- [ ] 上映中にイヤホンを挿す・抜くと、音がついていく

## 5. 書き出し

- [ ] 用途を選ぶと、長さ・ファイルの大きさ・かかる時間の目安が出る
- [ ] 書き出したファイルが OS の標準のプレーヤーで再生でき、上映と同じ見た目で、BGM が入り、最後に音も消える
- [ ] 書き出し中にダイアログを閉じても続き、上部の帯に進み具合が出る。終わるとダイアログが開いて知らせる
- [ ] 中止すると途中のファイルが残らない
- [ ] 書き出し中にアプリを閉じると、途中のファイルが残らない

## 6. 長時間

- [ ] ループする作品を、実際の上映ウィンドウで4時間以上流す。止まらず、メモリが増え続けない（Windows はタスクマネージャー、macOS はアクティビティモニタで見る）
