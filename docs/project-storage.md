# プロジェクトの保存と素材の取り込み

> 決定日: 2026-10-22。[完成までの手順](roadmap.md)の段階2の2番と3番。処理は [`src-tauri/src/project.rs`](../src-tauri/src/project.rs)（保存）、[`history.rs`](../src-tauri/src/history.rs)（元に戻す）、[`session.rs`](../src-tauri/src/session.rs)（編集中の状態）、[`editor.rs`](../src-tauri/src/editor.rs)（管理画面のコマンド）、[`import.rs`](../src-tauri/src/import.rs)（取り込み）にある。

## 1. 保存の形

1つのスライドショーを1つのフォルダにする（相談して決定）。

```
<アプリのデータフォルダ>/projects/
  └ show-1792648800000/
      ├ project.sqlite   定義（JSON）、題名、枚数、更新日時
      └ media/           取り込んだ写真・動画のコピー（1.jpg、2.mp4 …）
          └ thumbs/      一覧用の縮小画像（1.jpg.jpg …）
```

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 単位 | 1作品1フォルダ。データベースと素材を同じフォルダに置く | フォルダごと移動・複製・バックアップできる。「ほかの場所から開く」はこのフォルダを開く |
| 置き場所 | 新しい作品はアプリのデータフォルダの `projects/` に作る。フォルダ名は作った時刻 | 保存場所を意識させない（画面草案のA）。題名を変えてもフォルダ名は変わらない |
| 定義の持ち方 | `ShowDefinition` をJSONのまま1行に持つ | 素材とスライドを表に分けると、型を変えるたびに表も変える必要がある。定義は写真の画素を含まないので小さく、丸ごと書いても速い |
| 定義の変換 | 版1から版2へ: 見た目の設定のトランジションの長さが1秒（版1の初期値）なら「決めていない」にする。ほかの長さはそのまま残す | 版1ではどのトランジションも初期値は1秒だったので、決めていないことにしても見え方は変わらない。肉球（版2で追加）を選んだときは、肉球の5秒になる |
| ホーム画面用の列 | 題名、枚数、最初のスライドのファイル、更新日時を別の列に持つ | 一覧を出すときに定義を読まずに済む |
| 版 | 表の形は SQLite の `user_version`、定義の形は `version` で表す。新しい版で作られたものは開かない。定義に `version` がないか、版0（書かれたことのない版）なら壊れたものとして扱う | 古い形を変換して読むときに、版の分からないものを今の版と取り違えない |

## 2. 自動保存

- 変更のたびに、その場でデータベースに書く。保存ボタンはない（画面草案のB-7）。
- WALモードで書く。書いている途中でアプリが落ちても、最後に書き終えた状態から開ける。
- 保存に失敗したら、理由を管理画面に返す（`saveError`）。次の保存が成功すると消える。
- 取り込みの途中でアプリを閉じた素材は、次に開いたときに「取り込みが途中で止まりました」という失敗にする。書きかけのファイル（`.part`）は消す。不完全なファイルを素材として使わない（概要の4.7）。

## 3. 元に戻す

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 記録の仕方 | 変更の前の定義を丸ごと残す | 定義は小さい。変更ごとに逆の操作を書くより間違いにくい |
| 残す範囲 | 開いている間だけ。最大100回 | 相談して決定。閉じると消える |
| まとめ方 | 同じ入力欄（`group`）への変更が1.5秒以内に続けば1回にまとめる | 1文字ずつ戻ると使いにくい |
| 取り込みの結果 | 元に戻す対象にしない。素材のファイルの情報（状態、大きさ、長さ、音の有無）は別に覚えておき、戻した定義にも重ねる | 戻したときに、コピーが終わった素材が「取り込み中」に戻らないようにする |

## 4. 素材の取り込み

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 追加したとき | 選んだファイルを、すぐに「取り込み中」の素材とスライドとして定義に足す。題名にはファイル名を入れる | コピーの完了を待たずに題名や説明を入力できる（概要の4.7） |
| コピーの順番 | 1つの作業用スレッドが、追加した順に1つずつコピーする | 同じディスクに同時に書いても速くならない。並びの上から使えるようになる |
| 書き方 | `<名前>.part` に書き、最後まで書いてディスクに書き出し、中身を確かめてから本来の名前に変える | 途中で止まっても、不完全なファイルを素材として扱わない |
| 確かめること | 写真は読み込んで向きを直した大きさを測る。動画は ffprobe で長さと音の有無を調べ、少し先の1枚を取り出して大きさを測る。どちらも一覧用の縮小画像を作る | 壊れたファイルを取り込みの時点で見つける。上映を始めてから読めないことに気づかせない |
| ファイル名 | 素材の番号と元の拡張子（`7.jpg`） | 同じ名前のファイルを何度取り込んでもぶつからない。元の名前は `originalName` に残す |
| 失敗したとき | 素材を「失敗」にして理由を書く。書きかけのファイルと縮小画像は消す。管理画面は「選び直す」（`replace_asset_file`）と「外す」を出す | 画面草案のB-3 |
| 対応していない種類 | コピーせずにすぐ「失敗」にする | 理由を表示して、外せるようにする |
| 進み具合 | `import-progress` イベントで、0.2秒に1回ほど、コピーした量と全体の量を送る。保存はしない | 取り込みの間だけの情報 |
| 作品を閉じたとき | 閉じた作品の残りのコピーはやめる。次に開いたとき、その素材は「取り込みが途中で止まりました」になる。コピーは開いた回ごとの番号（`epoch`）で持ち主を見分ける。同じ作品を開き直したときも、前の回のコピーを止めてから素材のフォルダを片付ける | 開いていない作品のデータベースを書き換えない。書きかけのファイルを片付けで消さない |
| 使われなくなったファイル | 作品を開いたとき、どの素材も使っていないファイルを `media/` から消す | 外した素材を、元に戻せる間は残しておく。閉じたら元に戻せないので消してよい |

ウォーターマークの画像のように、スライドにしない素材は `addSlides: false` で取り込む。

管理画面は縮小画像を Tauri の asset プロトコル（`convertFileSrc`）で読む。読めるのは、開いた作品の `media/` と、ホーム画面に出す縮小画像だけにしている。

## 5. 管理画面とのやり取り

定義はエンジン側（Rust）が持つ。管理画面は変更した定義を丸ごと送り、返ってきた状態を表示する。

| コマンド | 内容 |
| --- | --- |
| `list_projects` | `projects/` の作品を新しい順に返す |
| `create_project(title)` / `open_project(dir)` / `close_project` | 作品を作る・開く・閉じる |
| `show_state` | 開いている作品の状態 |
| `edit_show(show, group, revision)` | 定義を置き換える。`group` は変更した入力欄の名前。`revision` が今の値と違えば適用しない（[やり取り](ipc.md)） |
| `undo_show` / `redo_show` | 元に戻す・やり直す |
| `import_files(files, addSlides)` | ファイルを取り込む。新しい素材の番号も返す |
| `replace_asset_file(asset, file)` | 素材のファイルを選び直す |

どれも `ShowState`（フォルダ、素材のフォルダ、定義、元に戻せるか、やり直せるか、保存のエラー）を返す。取り込みが終わったときのように、コマンドへの返事以外で定義が変わったときは、`show-changed` イベントで同じものを送る。
