# 画面の作り（段階3〜5）

> 決定日: 2026-10-22。[完成までの手順](roadmap.md)の段階3〜5。画面の設計は[画面草案](ui-draft.md)に従い、ここには作るときに決めたことを書く。画面は [`src/lib/components/`](../src/lib/components/)、上映中の操作のエンジン側は [`slideshow.rs`](../crates/fluxlide-engine/src/slideshow.rs) と [`src-tauri/src/presentation.rs`](../src-tauri/src/presentation.rs) にある。

## 1. 画面と部品

| 画面草案 | 部品 | 内容 |
| --- | --- | --- |
| A. ホーム | `Home.svelte` | 新規作成、写真や動画のドロップ（新しい作品を作って取り込む）、最近の作品、ほかの場所から開く |
| B. 編集 | `Editor.svelte` | 上部の帯（名前、保存の状態、元に戻す・やり直す、タブ、上映する）、左に `SlideList`、中央に `Preview`、右に選んだタブの設定 |
| B. 写真・動画タブ | `SlidePanel.svelte` | タイトル・作者・説明、キャプションの表示、表示時間、トランジション、動画の範囲と音量。詳細設定にトランジションの長さ、ゆっくりズーム、表示位置 |
| B. 見た目タブ | `LookPanel.svelte` | キャプションのデザイン、ウォーターマーク（文字・画像、位置、不透明度、大きさ）、縦横比が合わない写真、トランジションと長さ、写真の表示時間、すべての写真のゆっくりズーム。詳細設定に文字の大きさとカスタムトランジション（WGSL） |
| B. 音楽タブ | `MusicPanel.svelte` | BGM（フォルダ・曲を個別に）、曲の一覧、シャッフル、音量、動画中に止める、音ズレ補正とテスト音。詳細設定にフェード・曲間・動画の前後の長さ |
| C. 出力先の選択 | `OutputDialog.svelte` | 画面の配置図、各画面に番号を表示、進め方・最後まで再生したら・順番、次回もこの画面を使う |
| D. 上映中の操作 | `Presenting.svelte` | 上映中の帯、今と次のスライド、この後の一覧、前へ・一時停止・次へ・暗転、BGM と次の曲、音量、音ズレ補正、キー操作 |
| E. 上映画面 | エンジン（`Overlay::title_card`） | 開始前と終了後の画面（マークと題名） |
| F. 動画に書き出す | `ExportDialog.svelte` | 用途（テレビ・プロジェクター、パソコン・動画サイト、スマホ・SNS、高画質）、長さ・ファイルの大きさ・かかる時間の目安、進み具合と残り時間、中止。詳細設定にフレームレートとビットレート |

画面の状態は `src/lib/show.svelte.ts` の `open` が持つ。Rust 側から返ってきた `ShowState` を表示し、変更は `open.edit(変更する関数, group)` で送る。古い状態からの変更が断られたら、同じ関数を新しい状態にかけて送り直す（[やり取り](ipc.md)）。

## 2. 決めたこと

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 開始前の画面 | 上映ウィンドウはマークと題名の画面で始まり、操作する人が「スライドを始める」（Space か →）を押すまで待つ。最初のスライドは読み込んでおく | 観客が入る前から映しておける。黒い画面で待たせない（画面草案のE-5） |
| 終了後の画面 | 最後のスライドのあとで「次へ」を押すと、終了の画面（開始前と同じ）にフェードする。「前へ」で最後のスライドに戻る | 自動で止まる設定（最後のスライドで停止）では最後のスライドを残す。終わりの合図は操作する人が出す |
| 一時停止 | 再生の時計を止める。写真も動画の絵もそのまま止まり、動画の音は止める。BGM も一時停止する。再開すると、動画の音は絵の位置から鳴り直す | 一時停止はたいてい話をするため。止めた時間だけ後ろのスライドが遅れる |
| 次へ・前へ | すぐに次（前）のスライドに入る。読み込みが済むまでは今のスライドのまま待つ。一時停止中に押すと再開する | 黒い画面やトランジションの途中を出さない |
| 暗転 | 上映を止めずに黒だけを出す（キャプションとウォーターマークも消す）。もう一度押すと戻る | 画面草案のD-4 |
| 上映画面のキー | 上映ウィンドウが前にある間、Esc・← →・Page Up / Page Down・Space・B をグローバルショートカットとして登録する | 上映ウィンドウにはwebviewがなく、キーを受け取れない。プレゼン用のリモコンは Page Up / Page Down を送る |
| Escで終わるとき | 画面が2台以上なら、操作用の画面で終了を確かめる。1台なら確かめずに終わる | 1台では確認の画面が上映の後ろに隠れて見えない |
| 画面が1台のとき | 選ぶ画面を出さず、「この画面に全画面で映します。終了するにはEscキーを押してください」と2.5秒出してから始める | 画面草案のC-3 |
| 次回もこの画面を使う | 画面の名前をこの機器の設定（`settings.json`）に残す。同じ名前の画面がつながっていれば、選ぶ画面を出さずに始める。「上映する」の右の ▾ でいつでも選び直せる | 画面草案のC。会場ごとの機器の情報なので作品には入れない |
| 進め方・最後・順番 | 作品の定義（`playback`）に残す | 「次回もこの画面を使う」で同じ設定がそのまま使われる |
| 各画面に番号を表示 | 各画面の中央に3秒、番号の小さなウィンドウを出す | 画面草案のC-2 |
| プレビュー | 選んだスライドを、はじめから見えている状態で止めて出す。「このスライドから再生」でそこから再生する。編集のたびに0.15秒待って作り直し、新しい方が映るまで古い方を出し続ける | 入力のたびに黒くならないようにする |
| 並べ替え | 番号の部分をつかんで上下に動かす。Alt + ↑ ↓ でも動かせる。Delete で外す | Windows ではファイルのドロップの仕組みがwebviewの中のドラッグ&ドロップを止めるので、ポインターの操作で作った |
| 元に戻すのキー | Ctrl+Z、Ctrl+Shift+Z、Ctrl+Y。入力欄の中では入力欄の取り消しを優先する | 入力中の1文字の取り消しと、作品全体の取り消しを混ぜない |
| 音ズレ補正 | 上映中に10ミリ秒ずつ変えられる。変えた値はこの機器の設定に残し、次の上映でも使う | 会場で聞きながら合わせる（画面草案のD-6） |
| マークの色 | 画面の中のマークは奥の2枚を文字の色で塗る | 暗い配色でネイビーの板が見えなくなる（画面草案の8の単色版と同じ考え方） |
| すべての写真のゆっくりズーム | 見た目の設定に `motion` を持つ。自分の設定がない写真はこれに従う。動画には使わない。スライドで「なし」を選ぶと、拡大1倍から1倍の動きを持たせて止める | 写真ごとに設定しなくても動きを付けられる。動画は動いているので重ねない |
| 書体 | Noto Sans JP だけを使い、選べるのは文字の大きさだけにする | 上映と書き出しで同じ文字になるよう、アプリに入れた書体だけで描く（[演出の技術検証](spike-captions-transitions.md)）。書体を増やすのは配布の容量と相談して決める |
| ウォーターマークの画像 | 写真と同じように作品のフォルダに取り込む（スライドにはしない）。別の画像に替えたり外したりしたら、使われなくなった画像を作品から外す | 元のファイルを動かしても消えない |
| カスタムトランジション | `.wgsl` を選ぶと、Rust 側が読み込んで GPU でコンパイルを試す。通ったものだけを見た目の設定に足し、トランジションの一覧に出す。通らなければコンパイラーの理由を出す | 上映を始めてから間違いに気づかないようにする。上映ではコンパイルできないものをフェードに置き換える（[データ構造](scene-model.md)）|
| 外したカスタムトランジション | それを使っていたスライドは見た目の設定に従い、見た目の設定はフェードに戻す | 一覧にないトランジションを選んだままにしない |
| BGM の曲の一覧 | 選んだフォルダや曲を Rust 側で読み、曲名を出す | 上映を始める前に、流れる曲を確かめられる |
| テスト音 | 「テスト音で合わせる」で、選んだ画面（次回も使う画面があればそれ）を全画面にし、1秒ごとに白く光らせて同時に「ピッ」と鳴らす。音ズレ補正を変えると、すぐに鳴り方が変わる。Esc か「テスト音を止める」で終わる | 会場の画面と音の出口の組み合わせで合わせる必要がある。テレビは映像の処理で遅れることもあるので、映す画面で光らせる |

| 書き出しの用途 | テレビ・プロジェクターは 1920×1080・12 Mbps、パソコン・動画サイトは 1920×1080・6 Mbps、スマホ・SNS は縦 1080×1920・8 Mbps、高画質は 3840×2160・40 Mbps。どれも 30 fps、音は AAC 192 kbps | 画面草案のF。詳細設定で変えられる |
| 書き出しの形式 | MP4（H.264・AAC）だけにする。詳細設定には形式を出すが、選べない | 同梱する FFmpeg が使えるのは OS の H.264 エンコーダだけで（[FFmpegの同梱](spike-ffmpeg-bundling.md)）、どの機器でも再生できる形式に絞る |
| 書き出す範囲 | 開始前の画面は入れず、最初のスライドから1周だけ流し、最後は黒にフェードする。BGM も入れ、最後の2秒で消す。音ズレ補正は入れない | 動画のファイルは見る側の機器で再生するので、会場の補正は要らない |
| 書き出しの目安 | 長さは並べた順のタイムラインから出す。ファイルの大きさは「最大」として映像と音のビットレートから出す。かかる時間は解像度とフレームレートから出した目安で、実際の GPU では測っていない | 写真が多いと H.264 は小さくなるので、大きさは上限に近い数字になる |
| 書き出し中 | ダイアログを閉じても続き、上部の帯に進み具合を出す。編集はできるが、書き出すのは始めたときの内容。終わったらダイアログを開いて知らせる。アプリを閉じると中止し、途中のファイルを消す | 長い作品の書き出しを待つ間も作業できるようにする |
